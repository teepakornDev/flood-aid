# Architecture decision records (ADR)

Use short dated files `NNNN-short-name.md` when making substantial decisions. Format:

```markdown
# ADR-NNNN: Title
Status: Proposed / Accepted / Superseded
Date: YYYY-MM-DD
Context: What problem exists?
Decision: What are we choosing?
Consequences: Benefits, risks, rejected alternatives
```
